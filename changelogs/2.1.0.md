# CustomDeathMessages 2.1.0 Changelog

## Fixes

- Fixed death messages not working on 1.8 - 1.12 when a player head dropped.
- Fixed PvP death messages not showing at all on 26.x.
- Fixed the weapon hover not showing the item's name and enchantments on 1.16 and newer.
- Fixed players getting credit for kills they didn't make (for example when the victim fell or was killed by a mob shortly after being hit).
- Fixed the wrong killer being shown after a hit was blocked or a totem was used.
- Fixed dying to your own arrow counting as a PvP kill.
- Fixed custom named players getting mob death messages.
- Fixed thorns, dragon breath and warden sonic boom messages never being used.
- Fixed hover messages ignoring the `showDeathMessages` gamerule and vanish plugins.
- Fixed a mistake in config.yml wiping all of your messages on reload.
- Fixed changes made to config.yml by hand being overwritten by `/cdm` commands.
- Fixed `/deathmessage` not doing anything.
- Fixed players being able to add colors and placeholders to death messages through item names and nicknames.
- Fixed the color before `%kill-weapon%` being lost when item hover is enabled.
- Fixed hex colors showing the wrong color on servers older than 1.16.
- Fixed a warning on newer Paper versions about the plugin listening to logins.

## New

- Any mob or damage cause can have its own messages: add a list named after it, for example `creaking-messages`.
- Added messages for the creaking and zombie nautilus, plus support for trader llamas and the parched.
- `%kill-weapon%` now works for mobs too (for example a skeleton's bow).
- An empty message list now uses the vanilla death message, and a blank message (`""`) hides it.
- Player heads are added to the death drops, so grave plugins can pick them up.

## Changes

- `message-cooldown` now only affects the death message, not heads, lightning or PvP messages.
- `/cdm list` shows messages with their color codes, and `/cdm set number` checks that values make sense.
- Lightning and head drops are now off by default for new installs. Existing configs are not changed.
- Update checks no longer run every time a player joins.
- Removed `CustomPlayerDeathEvent`. Plugins using it should use `PlayerDeathEvent` instead.
